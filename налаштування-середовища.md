# Практичне заняття. Налаштування середовища

**Дисципліна:** Технології розробки гібридних систем штучного інтелекту
**Коли виконати:** щонайпізніше за день до заняття
**Що знадобиться:** ноутбук з 8 ГБ оперативної пам'яті, близько 5 ГБ вільного місця на диску, стабільний інтернет

---

## Крок 1. Python 3.10 або новіший

Перевірте, чи Python уже встановлено. Відкрийте термінал (Windows — PowerShell; macOS — Terminal; Linux — будь-який термінал) і виконайте:

```bash
python --version
```

Якщо команда не знайдена або версія нижча за 3.10, спробуйте `python3 --version`. Якщо й це не допомогло — встановіть Python:

- **Windows:** завантажте інсталятор з https://www.python.org/downloads/. **На першому екрані інсталятора позначте пункт «Add python.exe to PATH»** — інакше команда `python` не буде знайдена.
- **macOS:** інсталятор з https://www.python.org/downloads/ або, якщо встановлено Homebrew, `brew install python`.
- **Linux (Ubuntu / Debian):** `sudo apt install python3 python3-venv python3-pip`.

Після встановлення закрийте термінал, відкрийте новий і ще раз перевірте версію.

> Далі в інструкції використовується команда `python`. Якщо у вашій системі працює лише `python3` (типово для macOS та Linux), пишіть `python3`.

## Крок 2. Віртуальне середовище

Віртуальне середовище ізолює пакети цього проєкту від решти системи.

**Windows (PowerShell):**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

Якщо PowerShell повідомляє, що виконання скриптів заборонено, один раз виконайте `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, підтвердіть і повторіть активацію.

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Після активації на початку рядка термінала з'явиться `(.venv)`. **Активувати середовище потрібно в кожному новому вікні термінала**, у тому числі на самому занятті.

## Крок 3. Python-пакети

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Буде встановлено три пакети: `z3-solver` (символьний розв'язувач; версію зафіксовано навмисно), `ollama` (клієнт для локальної моделі) та `pydantic` (валідація JSON).

## Крок 4. Ollama

Ollama запускає мовні моделі локально на вашому ноутбуці — безкоштовно та без облікового запису.

- **Windows:** завантажте інсталятор з https://ollama.com/download і встановіть. Ollama запускається автоматично й працює у фоновому режимі (значок у системному треї).
- **macOS:** завантажте застосунок з https://ollama.com/download, перемістіть його в теку «Програми» (Applications) і запустіть. У рядку меню з'явиться значок Ollama.
- **Linux:** `curl -fsSL https://ollama.com/install.sh | sh`. Сервіс запускається автоматично; якщо ні — виконайте `ollama serve` в окремому вікні термінала.

Перевірте: `ollama --version`.

## Крок 5. Мовна модель

Усі команди використовують одну й ту саму модель — `qwen2.5:3b` (≈2 ГБ). Це робить результати команд порівнюваними між собою. Використовувати інші моделі на занятті не потрібно.

Завантажте модель:

```bash
ollama pull qwen2.5:3b
```

Перевірте, що модель відповідає:

```bash
ollama run qwen2.5:3b "What is 2 + 2? Answer with one number."
```

Перша відповідь може з'явитися через 10–30 секунд, поки модель завантажується в пам'ять. Якщо модель запустилася в інтерактивному режимі, вийдіть командою `/bye`.

## Крок 6. Перевірка середовища

У теці репозиторію, з активованим віртуальним середовищем, виконайте:

```bash
python smoke_test.py
```

Скрипт перевіряє версію Python, встановлені пакети, роботу розв'язувача Z3 на тестовій задачі, доступність Ollama та здатність моделі повернути структурований JSON. Очікуваний результат:

```
[ OK ] Python 3.11.9
[ OK ] package z3 4.13.0
[ OK ] package ollama
[ OK ] package pydantic 2.x
[ OK ] Z3 solver: test problem solved correctly
[ OK ] Ollama server is running
[ OK ] model qwen2.5:3b is downloaded
[ OK ] model returned structured JSON in 4.2 s: {"city": "Kyiv", "country": "Ukraine"}

All checks passed. You are ready for the practical.
```

Кожен рядок `[FAIL]` супроводжується підказкою, що робити. Виправте проблему й запустіть перевірку ще раз. Рядок `[WARN]` про повільну модель не є помилкою, але варто врахувати його під час розподілу ноутбуків у команді.

## Типові проблеми

| Симптом | Що робити |
|---------|-----------|
| `python` не знайдено (Windows) | Перевстановіть Python, позначивши «Add python.exe to PATH», і відкрийте новий термінал |
| `python` не знайдено (macOS / Linux) | Використовуйте `python3` |
| Не встановлюється `z3-solver` | Оновіть pip (крок 5) і повторіть. Якщо не допомогло — повідомте викладача заздалегідь: частину з розв'язувачем можна виконати в Google Colab |
| `Ollama is not reachable` | Запустіть застосунок Ollama (Windows / macOS) або `ollama serve` (Linux) |
| `model qwen2.5:3b is not downloaded` | Виконайте `ollama pull qwen2.5:3b` |
| Модель відповідає понад хвилину | Закрийте браузер та інші важкі програми; на занятті працюйте на найшвидшому ноутбуці команди |
| Бракує місця на диску | Модель займає близько 2 ГБ; видаліть непотрібні моделі командою `ollama rm <назва>` |
| Завантаження моделі обривається | Повторіть `ollama pull` — завантаження продовжиться з місця зупинки |
| Помилка активації в PowerShell | Див. примітку до кроку 4 про `Set-ExecutionPolicy` |

## Запасний варіант: без локальної моделі

Якщо жоден ноутбук у команді не тягне модель `qwen2.5:3b`, можна використати безкоштовний рівень Google AI Studio:

1. Увійдіть на https://aistudio.google.com з обліковим записом Google і створіть API-ключ.
2. Встановіть клієнт: `pip install google-genai`.
3. Збережіть ключ у змінній середовища `GEMINI_API_KEY` — **не записуйте ключ у код і не комітьте його в репозиторій**.

Скрипт `smoke_test.py` цей варіант не перевіряє. Запустіть `python smoke_test.py --skip-llm`, щоб перевірити решту середовища, і **заздалегідь повідомте викладача**, що команда працюватиме через AI Studio.
